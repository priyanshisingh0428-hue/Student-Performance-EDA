# Student Performance EDA

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of student performance using Python.

## Objectives
- Analyze student performance.
- Understand the relationship between study time and grades.
- Visualize student marks using graphs.
- Identify factors affecting academic performance.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Student Mathematics Performance Dataset (`student-mat.csv`).

## Project Files
- `studentperformance.ipynb` – Python analysis and code.
- `student-mat.csv` – Dataset.
- `grade_histogram.png` – Grade distribution graph.
- `study_time_chart.png` – Study time visualization.
